Every mode, and what you get in it

Skins work in every mode with champion models. Builds depend on where the numbers come from: u.gg for most queues, op.gg for Arena.

Client-side, and nothing more

Skins are visible only to you. Nobody else in the game sees them, and they change nothing about how the game plays. The build guide is public u.gg and op.gg data anyone can open in a browser. tibbers gives you no competitive advantage and no information you couldn't get otherwise. It never modifies your League install: it works on the running game, with cslol's mod-tools, the same way Rose does on Windows.

Install

macOS

  1. Download, open the disk image, and drag Tibbers onto the Applications folder beside it.
  2. The first time, right-click the app and choose Open. macOS asks because the app isn't notarized. You only do this once.
  3. Start League as usual, hover a champion, click a skin.

Apple Silicon, macOS 26. Updates arrive inside the app.

Download for macOS

Windows

  1. Download and unzip, then run Tibbers.
  2. Windows may warn about an unknown publisher the first time. Choose More info, then Run anyway.
  3. Start League as usual, hover a champion, click a skin. No password prompt.

Windows 10 or 11. New, and less travelled than the Mac build.

Download for Windows

tibbers is mostly glue. The hard parts are other people's work: cslol-manager and the League Toolkit for the overlay builder and patcher, u.gg and op.gg for the statistics, and a nod to Rose, the Windows skin changer that inspired it.
