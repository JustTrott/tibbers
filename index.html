Pick a skin in champ select. It's on your game when it starts.

Your new companion for League of Legends, on Windows and macOS. tibbers is a skin changer and build guide in one small window: every skin of the champion you hover, right there in the lobby, applied the moment the game launches, with the runes and items to go with it. Free, open source, and it never touches your League install.

More League, less tabbing out.

Champ select lasts about a minute, and the decision competes with runes, summoner spells and lobby chat. tibbers sits beside the game and amplifies that minute: it reads the champion you hover from the client's own API, puts every one of that champion's skins on screen, remembers what you liked last time, and has the build ready before you lock in. Skins you don't own included.

Nothing you see is made up. Every name, splash and icon comes from the League client. The builds and counters come from u.gg and op.gg, and every page links back to where its numbers came from.

And nothing here is an edge. A skin is cosmetic and only you see it. The build suggestions are public stats anyone can open in a browser. tibbers just saves you the tab-out, on Windows and on macOS alike.

What it does

  • On hover

    Skins appear the instant you hover a champion, before you lock in, and start building quietly in the background so they're ready if you take the pick. A skin that can't be built stays on screen, dimmed, so absence is visible rather than mysterious.

  • Remembered

    The skin you like on each champion, and the chroma on each skin, put back automatically the next time you lock that champion.

  • Builds

    While you decide, it pulls the champion's runes, items, skill order and matchups from u.gg, and Arena augments, items and a tier list from op.gg. One click imports the build straight into the client, so you don't have to tab out to a stats site.

  • Out of the way

    Close the window and it drops into the menu bar or system tray, still watching champ select. A small picker raises itself when you lock a champion and closes when the lobby ends.

  • One prompt

    On macOS, applying a skin needs your password once per game, or never again after an optional one-time setup. On Windows there is nothing to elevate, so it never asks.

How it works, and why your install is safe

Riot's client verifies its own files and repairs anything changed, so tibbers never writes into the League installation. It works on the running game instead, in three small steps.

  1. 1 · Build

    A few kilobytes, out of your own files

    When you pick a skin, tibbers writes a tiny replacement game archive that points the base skin's asset references at the skin you chose. Those files already ship with your install, so no skin art is ever downloaded and no skin repository is contacted. A mod is a rewrite of pointers, not a download.

  2. 2 · Wait

    A patcher that waits for the game

    It starts a small patcher, the mod-tools from cslol-manager, that watches for the game to launch. The game is never frozen or suspended, and what the patcher is about to run is printed before it runs.

  3. 3 · Redirect

    Reads go to the overlay, the install stays put

    When the game starts, the patcher redirects its archive reads into that overlay. Only you see the skin. Close the game and nothing is left behind.

Is it bannable? In practice, no. Custom skins are client-side only, nobody else sees them, and they change nothing about how the game plays, so Riot treats them as use-at-your-own-risk rather than something it actions. Rose, the equivalent tool on Windows, injects the same way without people getting banned. The caveats: don't expect Riot support if something breaks, and Korea, Turkey and Russia enforce more strictly than NA or EU.

Install

macOS

  1. Download, open the disk image, and drag Tibbers onto the Applications folder beside it.
  2. The first time, right-click the app and choose Open. macOS asks because the app isn't notarized. You only do this once.
  3. Start League as usual, hover a champion, click a skin.

Apple Silicon, macOS 26. Updates arrive inside the app.

Download for macOS

Windows

  1. Download and unzip, then run Tibbers.
  2. Windows may warn about an unknown publisher the first time. Choose More info, then Run anyway.
  3. Start League as usual, hover a champion, click a skin. No password prompt.

Windows 10 or 11. New, and less travelled than the Mac build.

Download for Windows

tibbers is mostly glue. The hard parts are other people's work: cslol-manager and the League Toolkit for the overlay builder and patcher, u.gg and op.gg for the statistics, and a nod to Rose, the Windows skin changer that inspired it.
